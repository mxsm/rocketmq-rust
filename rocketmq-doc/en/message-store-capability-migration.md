## Migration order

1. Finish transaction, schedule, timer, and pop ports.
2. Finish failover, replication, and pre-online ports.
3. Finish admin and control-plane ports.
4. Retain the concrete store only at composition and lifecycle ownership roots.

The current release gate is at most 80 facade methods used by Broker production code. This report does not claim that all compatibility paths are removed; it makes every remaining path owned and mechanically non-growing.
