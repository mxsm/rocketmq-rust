# Global dashboard overview

The authenticated overview command reuses the Cluster, Topic, Consumer and Producer managers and checks connection revision before and after the combined read. No additional admin session or detached worker is created.

Statuses distinguish UNCONFIGURED, DOWN (all metrics unavailable), PARTIAL, and READY (queries returned). Each nullable metric also carries complete, reported, partial, or unknown quality. Topic catalog counts are reported because the existing catalog does not expose source coverage. Consumer and Producer counts use workspace inventory failure evidence; total lag sums only observed nonnegative values and is explicitly partial if any group is missing. No unavailable metric is substituted with zero.

The desktop overview presents Broker availability and data quality before Topic count, Consumer-group count, combined produce/consume throughput, and observed lag. Producer-group coverage remains visible with a directory action. Broker activity requires a successful status read and the reported activity field; missing or malformed runtime counters/rates remain unknown instead of inheriting the DTO's zero defaults. The Broker table and secondary Broker rankings/TPS analysis share the same response. Received totals are cumulative get counters; production deltas use the Broker's local day. Topic queue/message rankings and type distribution remain available in the expandable analysis section.

The page toolbar refreshes every read region, including the selected historical queries. Each region retains its last successful response on a same-scope refresh failure and labels it as previous data. The toolbar's last successful page refresh advances only after all requested regions succeed. Server overview observation time and client response receipt time are labeled separately; neither is a per-Broker last-seen measurement. Page cleanup invalidates pending results, while routing remounts the page on connection revision changes. Actions use the shared navigation store to open NameServer configuration, the exact Broker address, or a lagging Consumer group's progress in NameServer scope.
